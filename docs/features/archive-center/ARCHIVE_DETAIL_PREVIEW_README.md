# 档案详细预览功能说明

## 概述

本文档说明了档案中心的详细报告预览功能，该功能允许用户在个人中心的"我的档案"页面中预览完整的档案报告。

## 功能位置

**路径**: 个人中心 -> 我的档案 -> 档案列表 -> 点击"预览"按钮

## 组件结构

### 新增组件

- **`ArchiveDetailPreview.vue`**: 档案详细预览组件
  - 位置: `src/components/archive-center/ArchiveDetailPreview.vue`
  - 类型: 模态框组件
  - 触发方式: 在 `ArchiveReport.vue` 中点击档案卡片的"预览"按钮

### 修改组件

- **`ArchiveReport.vue`**: 档案报告列表组件
  - 集成了新的详细预览功能
  - 移除了旧的简单预览模态框
  - 新增完整的报告数据生成逻辑

## 预览内容

### 1. 报告头部
- 报告名称
- 创建时间
- 模块数量
- 操作按钮（打印、下载、关闭）

### 2. 报告模块（模拟3个）

#### 模块一：成果奖励 🏆
- **图表**: 柱状图展示论文、专利、证书、项目的统计数据
- **总结**: 本学期成果奖励情况的详细描述
- **关键指标**:
  - 总计奖项: 12项
  - 核心论文: 3篇
  - 授权专利: 2项
  - 完成度: 85%

#### 模块二：工作量统计 📊
- **图表**: 柱状图展示教学、科研、管理、服务的工作量分布
- **总结**: 本学期工作量情况的详细描述
- **关键指标**:
  - 教学学时: 368时
  - 科研项目: 5项
  - 管理工作: 2项
  - 超额完成: 20%

#### 模块三：数字素养 💻
- **图表**: 柱状图展示信息技术、数据分析、工具应用、创新能力
- **总结**: 数字化教学能力的详细描述
- **关键指标**:
  - 掌握工具: 15种
  - 开发应用: 3个
  - 培训证书: 高级
  - 综合评分: 88分

### 3. 报告总体总结

#### 概述
全面展示教师在本学期的工作成果和专业发展情况，包括教学、科研和专业能力提升方面的成绩。

#### 关键亮点
1. 成果奖励丰硕，获得国家级、省级、市级奖项共12项
2. 工作量饱满且分布合理，教学学时超额完成20%
3. 数字素养能力突出，掌握现代教育技术工具
4. 论文发表质量高，核心期刊论文3篇
5. 专利申请与授权进展良好

#### 改进建议
1. 继续保持科研工作的高投入
2. 加强跨学科交流与合作
3. 进一步提升数字化教学创新能力
4. 注重工作与生活平衡
5. 积极参与学术会议和专业培训

## 技术实现

### 数据结构

```javascript
{
  name: "报告名称",
  createTime: "创建时间",
  modules: [
    {
      name: "模块名称",
      icon: "模块图标",
      chartTitle: "图表标题",
      chartType: "图表类型",
      chartData: [
        { label: "标签", value: 数值 }
      ],
      summary: "模块总结文本",
      metrics: [
        { label: "指标名称", value: "指标值" }
      ]
    }
  ],
  overallSummary: {
    overview: "总体概述",
    highlights: ["亮点1", "亮点2", ...],
    recommendations: ["建议1", "建议2", ...]
  }
}
```

### 组件通信

```vue
<!-- 在 ArchiveReport.vue 中 -->
<ArchiveDetailPreview 
  v-if="previewReportData" 
  :reportData="previewReportData"
  @close="closeReportPreview" 
/>
```

4. **打印支持**:
   - 优化打印样式
   - 隐藏操作按钮

## 使用示例

### 触发预览
```javascript
// 在档案列表中点击预览按钮
<button class="action-btn preview-btn" @click="previewReport(report)">
  预览
</button>
```

### 数据处理
```javascript
const previewReport = (report) => {
  // 生成完整的报告数据
  previewReportData.value = {
    name: report.name,
    createTime: report.createTime,
    modules: [...], // 三个模块数据
    overallSummary: {...} // 总体总结
  }
}
```

### 关闭预览
```javascript
const closeReportPreview = () => {
  previewReportData.value = null
}
```

## 注意事项

1. **数据模拟**: 当前使用的是模拟数据，实际应用中需要从后端API获取真实数据
2. **性能优化**: 对于大量模块的报告，建议使用虚拟滚动
3. **浏览器兼容**: 使用了现代CSS特性，需要考虑IE浏览器的兼容性
4. **打印功能**: 部分浏览器的打印样式可能需要单独调整
